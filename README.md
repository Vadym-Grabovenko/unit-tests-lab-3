Команди для запуску тестів/покриття:

2. python -m pytest (прогон тестів)
3. python -m pytest --cov=delivery --cov-report=html (прогон тестів та формування HTML-звіту з coverage треба відкривати index.html, інші відповідають за елементи веб-сторінки)/
